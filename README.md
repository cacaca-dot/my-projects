# 🚀 Portofolio Proyek Saya

Selamat datang di repositori portofolio saya! Berikut adalah proyek-proyek yang pernah saya kerjakan:

### 1. BitesLog — Jurnal Kunjungan Kafe
* **Deskripsi:** Aplikasi mobile untuk menemukan kafe, mencatat kunjungan dan ulasan, menyimpan kafe ke watchlist, serta membuat daftar kafe pribadi. Data aplikasi disimpan lokal di perangkat.
* **Teknologi:** Flutter, Dart, SQLite (`sqflite`), SharedPreferences, OpenStreetMap
* **Kode Sumber:** [Lihat Kode](./biteslog-mobile-app)

### 2. Google Offices — Aplikasi Informasi Kantor
* **Deskripsi:** Aplikasi Flutter untuk menjelajahi dan mencari kantor Google berdasarkan nama atau alamat, lalu melihat detail kantor seperti alamat, nomor telepon, region, dan koordinat.
* **Teknologi:** Flutter, Dart, Material Design
* **Kode Sumber:** [Lihat Kode](./dicoding-flutter-app)

### 4. Expense Tracker
* **Deskripsi:** Aplikasi web untuk mencatat pemasukan dan pengeluaran, mencari serta mengelola transaksi, dan melihat ringkasan saldo. Data disimpan secara lokal di browser.
* **Teknologi:** HTML5, CSS3, JavaScript, LocalStorage
* **Kode Sumber:** [Lihat Kode](./expense-tracker-web)
